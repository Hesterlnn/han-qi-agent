# 韩琦智能体

韩琦智能体是一套以北宋名臣韩琦为人物基础的对话与研究工具。它既可以用于日常聊天、情境演绎和现实任务，也可以依据用户指定的文献回答问题。

当前发布版本：**V1.1**

## 可以做什么

- 与韩琦进行自然对话；
- 体验历史、现代、穿越或架空情境；
- 请它帮助分析问题、安排步骤或起草文字；
- 添加自己的文献资料，并请它依据这些材料查找和回答；
- 在用户主动打开或明确要求时进行联网检索。

## 选择适合你的版本

| 版本 | 适合人群 | 使用方式 |
|---|---|---|
| 普通聊天框版 | 希望快速体验、不想安装程序的用户 | 将提供的提示词和知识包加入常用聊天平台 |
| 本地 API 网页版 | 希望在浏览器中使用，并添加本地文献的用户 | 在电脑上启动网页，填写所选模型服务的配置 |
| 完整 Agent／研究版 | 使用 Codex、Cursor 等 Agent 工作平台的用户 | 将项目作为 Agent 或 Skill 加载 |

## 使用边界

- 联网检索默认关闭，只在用户主动打开或明确要求时使用；
- 考据或文献研究需要先指定、上传或添加材料；
- 情境和同人内容可以虚构，但不会把虚构内容当作真实史料；
- 请勿在公开文件中填写 API Key，个人配置应保存在本机的 `.env` 或本地配置文件中。
