# 启动本地聊天

该入口适合希望自由选择 GPT 或国内模型、但不使用IDE的用户。需要 Python 3 和相应模型服务的 API Key。

## 最短启动流程

1. 复制 `../provider-config/providers.example.json` 为 `../provider-config/providers.local.json`。示例文件当前选中 DeepSeek，仅用于展示可运行的配置结构，不表示默认或推荐供应商。
2. 复制本目录的 `.env.example` 为 `.env`，填写所选供应商对应的密钥。不要把 API Key 写进JSON。
3. 在本目录运行：

```powershell
python server.py --config ..\provider-config\providers.local.json
```

浏览器将打开 `http://127.0.0.1:8765/`。关闭终端或按 Ctrl+C 即停止服务。

如需导入PDF，在本目录额外运行：

```powershell
python -m pip install -r requirements.txt
```

`server.py` 会自动读取本目录的 `.env`，无需把密钥设置成系统级环境变量。若系统环境变量和 `.env` 同名，系统环境变量优先。也可用 `--env-file 路径` 指定其他文件。

`.env` 是明文密钥文件，已经被本目录的 `.gitignore` 排除；仍不要上传、分享或提交它。若不想在磁盘保存密钥，也可以不创建 `.env`，继续使用系统或当前终端的环境变量。

示例同时列出以下典型服务和模型名称：

| `active_provider` | 服务平台 | 示例 `model` |
|---|---|---|
| `deepseek` | DeepSeek 开放平台 | `deepseek-v4-flash` |
| `openai` | OpenAI API | `gpt-5.6-terra` |
| `qwen-bailian` | 阿里云百炼／通义千问 | `qwen3.7-plus` |
| `zhipu` | 智谱开放平台 | `glm-5` |
| `volcengine-ark` | 火山方舟／豆包 | `doubao-seed-2-0-lite-260215` |
| `custom` | 其他 OpenAI 兼容服务 | `provider-model-name`（占位） |

这些都是典型示例，不是默认推荐，模型可用性也取决于地域、账户权限和供应商更新。切换服务时，编辑 `providers.local.json` 中的 `active_provider`；同时核对该条目的 `base_url` 和 `model`，并在 `.env` 中填写对应密钥。百炼的地址需要按地域和工作空间填写；火山方舟部分账户或自部署服务需要填写控制台生成的 Endpoint ID。ChatGPT/Codex订阅与OpenAI API平台分别计费，网页无法直接使用聊天产品的登录凭证。

这是本地单用户入口。若要部署到公网，必须增加登录认证、HTTPS、限流、日志脱敏和独立的密钥管理；不要直接把此开发服务器暴露在公网。

## 本地文献库

在网页的“本地文献库”区域点击“添加文件”或“添加文件夹”。文献会保存在本机。启用“使用本地文献库”时，网页会查找与问题相关的内容，并把少量相关节选发送给模型。点击“清空会话”不会删除文献；“清空文献库”会在确认后删除全部本地文献。

支持TXT、Markdown、CSV、JSON、HTML、DOCX和PDF。如果PDF是扫描图片，需要先进行文字识别。单个文件上限25 MB，单次导入总量上限50 MB。

## 按需联网检索

联网检索默认关闭，网页只显示一个“联网检索”开关，不需要选择搜索方式。

使用本包默认的 DeepSeek 配置时，联网检索直接使用同一个 `DEEPSEEK_API_KEY`，不需要另外申请或填写联网密钥。填写 DeepSeek API Key 并重启服务后，右上角显示“联网检索可用”即可使用。

开关打开期间每次提问都会联网，直到手动关闭或刷新页面。选择“考据”或启用本地文献库不会自动打开联网开关。若改用其他模型服务，是否可用取决于该服务是否提供联网能力；普通用户仍不需要选择具体搜索方式。
