# 韩琦智能体：普通聊天框用法

## 最简单的使用方式

1. 新建一个支持上传文件的聊天。
2. 上传《韩琦智能体－通用知识包.md》。
3. 把《启动提示词.md》的内容作为第一条消息发送。
4. 直接聊天，不需要学习命令。

如果平台支持“自定义智能体”或“知识库”，把启动提示词放进系统指令，把知识包上传到知识库，只需配置一次。

普通聊天框不能直接读取电脑里的文件夹。要使用文献研究功能，必须上传文件、导入平台知识库，或改用能够访问本地文件的 Agent/本地研究工具。

## 可以这样说

- `韩相公，今天不谈国事，你陪我聊聊。`
- `假设你刚从仁宗的葬礼回来，我来见你。`
- `如果你来到现代，会怎么看公司的绩效考核？`
- `项目延期，所有人都推卸责任。请你接手处理。`
- `以我上传的三篇论文为文献库，研究韩琦与富弼的关系。`

## 四种模式

- 闲谈：轻松对话，不主动考据。
- 情境：历史、穿越、现代或架空演绎。
- 任事：让韩琦实际完成任务。
- 考据：仅限已经指定的文献库。

## 注意

- 同人情境可以虚构，但虚构对白不等于史料。
- 不支持文件上传的平台只能使用启动提示词，人物稳定性会有所下降。
- 新建普通会话后，通常需要重新上传知识包和发送启动提示词。
